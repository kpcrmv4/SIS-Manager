# P3 — Integrations (LINE · print) · acceptance matrix

Written before P3 code (LOOP §4). Row ids prefix the Playwright test titles. `👤` rows need a
person with real hardware or a real LINE account (`manual_verify`) and can only be marked code-green.

Contract shipped by the orchestrator first (`20260924100000_p3_contract.sql`):
`new_group_bind_code(branch)` owner · `bind_staff_group(branch, code, group_id)` service ·
`line_link_attempt(branch, customer, ref)` service, 5 failures / 15 min / LINE user / branch → `THROTTLED` ·
`send_line_test(branch)` owner → one `test` outbox row to the staff group. `jszip` added for the setup ZIP.

LINE HTTP calls go to `LINE_API_BASE` (default `https://api.line.me`); specs point it at a local
mock server so no real message ever leaves the machine.

Legend: ☐ open · `pass <spec>` proven by a spec that can go red.
