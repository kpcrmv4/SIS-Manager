# Test plan — P1 Schema + RLS + RPCs

Plan reference: `CLAUDE.md` §4 (data model, RPC list) · `docs/design/DESIGN.md` "กฎธุรกิจ"
ID prefix: `P1-<FEATURE>` · specs: `tests/e2e/P1-*.spec.ts` (DB-level, service role + per-role sessions)

Fixture for every row: branches **A** (`RMI`) and **B** (`KNM`); users `staff@A`, `bar@A`, `staff@B`,
`owner` (all branches). "as X" = a PostgREST call carrying X's session. A row that says a rival
row is invisible names that rival row, which exists in branch B while the line runs.
