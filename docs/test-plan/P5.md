# P5 — Close (demo reset + seed + demo login · acceptance reconcile) · acceptance matrix

Written before P5 code (LOOP §4). Row ids prefix the Playwright test titles.

Demo set (CLAUDE §9): three branches **RMI รามอินทรา · KSN เกษตร-นวมินทร์ · BNA บางนา**, accounts
`demo.owner` / `demo.bar` / `demo.staff` whose passwords come from `SEED_OWNER_PASSWORD` /
`SEED_BAR_PASSWORD` / `SEED_STAFF_PASSWORD` (never in code). `npm run demo:reset` wipes and re-seeds
**only** those three branches and those three accounts — E2E fixture branches (Z…) and anything else
are never touched. Seeding goes through the real RPCs as the demo accounts, so history, events and
the LINE outbox look like real use; only aged states (expired, no-show, past nights) are adjusted
with scoped SQL afterwards.
