# Test plan — P2 Screens (workers A / B / C)

Plan reference: `CLAUDE.md` §10 P2 · `docs/design/demo.html` (every screen) · `docs/design/DESIGN.md` · P1 contract:
`src/lib/{deposit,booking}/actions.ts`, `src/lib/customer/auth.ts`, `src/lib/scan/*`, `src/lib/errors.ts`.
ID prefix: `P2-<FEATURE>` · specs `tests/e2e/P2-A*.spec.ts`, `P2-B*.spec.ts`, `P2-C*.spec.ts` (fixture: branches ZTA/ZTB, roles
staff/bar/owner/staffB/multi from `tests/e2e/fixtures`). Every list page is checked at **390px (cards)** and **1280px (table)**;
a responsive row asserts which layout is visible. Four data states on every data view: skeleton · error+retry · empty · data.
